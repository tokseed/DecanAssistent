# Онлайн-деканат

[![Status](https://img.shields.io/badge/status-в_разработке-orange)]() [![Python](https://img.shields.io/badge/python-3.10%2B-blue)]() [![FastAPI](https://img.shields.io/badge/FastAPI-backend-green)]() [![MS SQL](https://img.shields.io/badge/MS_SQL-database-red)]()

«Онлайн-деканат» — это интеллектуальный цифровой помощник для студентов в виде десктопного приложения, который считывает фотографии документов с помощью компьютерного зрения (OpenCV + OCR) и мгновенно отвечает на вопросы, основываясь на актуальных правилах и регламентах вуза.

## Технологии
- **Python** — основной язык программирования для логики и бэкенда
- **FastAPI** — веб-фреймворк для создания REST API бэкенда
- **OpenCV** — библиотека компьютерного зрения для предобработки и выравнивания фотографий документов
- **OCR (EasyOCR / PaddleOCR)** — распознавание текста на изображениях студенческих документов
- **MS SQL Server (T-SQL)** — реляционная база данных для хранения правил, регламентов и истории запросов
- **pyodbc / SQLAlchemy** — инструменты для подключения и работы с MS SQL из Python
- **PyQt6 / PySide6 (или CustomTkinter)** — инструменты для разработки графического десктопного интерфейса (Desktop Frontend)

## Использование
Запустите десктопное приложение, загрузите фотографию студенческого документа (через кнопку или перетаскивание Drag-and-Drop) и задайте интересующий вас вопрос в текстовом поле. Приложение обработает снимок через OCR, найдет ответ в базе правил MS SQL и выведет его со ссылками на регламенты.

Пример отправки запроса к бэкенду (FastAPI) из кода клиента:
```python
import requests

url = "[http://127.0.0.1:8000/api/ask](http://127.0.0.1:8000/api/ask)"
files = {"file": open("student_card.jpg", "rb")}
data = {"question": "Какие правила получения справки?"}

response = requests.post(url, files=files, data=data)
print(response.json())  # Выведет ответ секретаря со ссылками на правила
